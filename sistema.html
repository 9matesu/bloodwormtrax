// 8 vozes, 66 parâmetros, nenhum sample
const grain = (bytes, position) => {
  const window = bytes.slice(position, position + 4096)
  const density = 0.42
  return window.map((b) => (b / 255) * density)
}

const voice = new Voice({ voices: 8, mode: "texture" })

Um executável entra como matéria-prima. O motor lê os bytes e monta o buffer.
O buffer é fatiado em janelas curtas. Densidade e tamanho definem a textura.
A posição percorre o binário. O resultado é drone e ruído que não existe em sample.
Tudo vira um arquivo .opcoda com os 66 parâmetros e a origem.
